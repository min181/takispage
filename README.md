# Taki's Apps

## About

This is a static website for iOS apps and small tools developed by Taki, published with GitHub Pages.

## Pages

- `index.html`: Brief app introductions with App Store, per-app privacy policy, and shared contact links
- `screen-palette.html`: Redirect to `index.html#screen-palette` for existing links
- `screen-palette-privacy.html`: Privacy Policy for Screen Palette
- `koroai.html`: Redirect to `index.html#koroai` for existing links
- `koroai-privacy.html`: Privacy Policy for Koroai
- `gesture-video-player-privacy.html`: Privacy Policy for Gesture Video Player
- `contact.html`: Contact page for Taki's apps

## Tech

- HTML / CSS
- GitHub Pages

## Notes

All page links are relative links so the site works both locally and on GitHub Pages.
